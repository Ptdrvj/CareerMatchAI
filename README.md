# CareerMatch AI — Resume & Job Matching

CareerMatch AI is a Generative AI application that analyzes a candidate's resume against a job description to identify matching skills, highlight potential skill gaps, and generate personalized improvement recommendations and interview questions.

## Features

- **Resume Parsing:** Extract text from PDF, DOCX, and TXT files.
- **AI-Powered Resume Analysis:** Use Google's Gemini API to compare a resume with a job description.
- **Skill Gap Analysis:** Identify matched skills, missing skills, and additional relevant skills.
- **Match Score:** Generate an AI-based estimate of how well a resume aligns with a job description.
- **Personalized Recommendations:** Suggest areas for improvement based on the analysis.
- **Interview Preparation:** Generate relevant technical interview questions.
- **Interactive Dashboard:** View analysis results using Streamlit.
- **Export Options:** Download the analysis as JSON and a Markdown interview-preparation sheet.

## Tech Stack

- **Language:** Python
- **Frontend:** Streamlit
- **LLM:** Google Gemini API
- **Document Parsing:** PyPDF, python-docx
- **Data Validation:** Pydantic
- **HTTP Requests:** Requests
- **Data Handling:** Pandas

## How It Works

1. Upload a resume in PDF, DOCX, or TXT format.
2. Enter the target job description.
3. The document parser extracts and cleans the resume text.
4. The application sends the resume text and job description to the Gemini API with analysis instructions.
5. Pydantic validates the structure of the generated response.
6. The dashboard displays the match score, skill analysis, recommendations, and interview questions.

## Prerequisites

- Python 3.10 or higher
- A Google Gemini API key from [Google AI Studio](https://aistudio.google.com/)

## Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/YOUR_USERNAME/CareerMatchAI.git
cd CareerMatchAI
```

**2. Install dependencies**

```bash
python -m pip install -r requirements.txt
```

**3. Configure the API key**

Create a `.env` file if your application configuration supports loading it, and add:

```text
GEMINI_API_KEY=your_gemini_api_key
```

Alternatively, enter the API key in the application's sidebar if that option is enabled.

Never commit your actual `.env` file or API key to GitHub.

**4. Run the application**

```bash
streamlit run app.py
```

Open the local URL displayed in your terminal to use the application.

## Limitations

- Match scores and recommendations are generated by an LLM and may not always be factually accurate.
- Skills absent from a resume are not necessarily skills the candidate lacks.
